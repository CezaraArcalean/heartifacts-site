# Heartifacts brand assets

This directory contains public, web-ready derivatives of Heartifacts' official visual identity.

## Logo rule — non-negotiable

The Heartifacts logo/wordmark is an official fixed brand asset.

**Do not redraw, reshape, recolor, warp, distort, restyle, regenerate, trace differently, or otherwise modify the logo itself.**

Allowed treatment includes:

- resizing proportionally;
- positioning it in different layouts;
- placing it on or around other artwork;
- adding decorative elements around it;
- cropping surrounding artwork where the logo itself remains intact and readable;
- using separate official logo variants only when the band has explicitly supplied those variants.

If a composition containing the logo needs to change, edit the composition around the logo rather than the logo artwork.

## Visual direction

The established Heartifacts identity is built around:

- near-black / black;
- vivid electric blue;
- hot pink / magenta;
- purple and deep violet;
- sprayed, painted, splattered and distressed textures;
- a punky / angry / pretty balance;
- energetic, playful composition rather than corporate polish.

The website should use these colors intentionally. Not every section needs to be equally loud: quieter black or light zones make the saturated artwork hit harder.

## Source vs website files

Master artwork is not stored here as a working archive. Keep original PSDs, full-resolution exports and other source files in the band's proper storage.

Only public, web-appropriate assets should be committed to this repository.

Recommended website assets once copied in:

```text
assets/brand/heartifacts-logo.svg
assets/brand/heartifacts-emblem.webp
assets/brand/heartifacts-texture.webp
```

The supplied official SVG should be preferred for the standalone wordmark where practical because it stays sharp at any display size.

## Performance

Large artwork should be exported to an efficient web format and sensibly resized before being committed. Decorative textures do not need print-resolution source files.

Do not trade away recognisable Heartifacts texture just to save a few kilobytes, but do not ship multi-megabyte source artwork when a visually equivalent web derivative will do.
